# edmondsim1010.github.io

Personal site. Plain HTML and CSS, no build step, hosted on GitHub Pages.

- `index.html` — the whole site, one page
- `style.css` — the styles
- `img/` — web-sized photos and project screenshots
- `cv.pdf` — current CV (replace the file to update it)
- `projects.html` — redirect kept so old links still work

To update: edit `index.html`, commit, push.
